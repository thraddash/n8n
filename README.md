# n8n 

## Testing
* create new workflow, manual trigger a button on n8n that create a new spreadsheet in Google drive
* create new workflow with form submission that appends data over to an existing Google spreadsheet, n8n filter only if status is active an email will be sent out
* n8n fetches newly created ticket every 5 minutes from zendesk api, delivery alert over to slack channel using slack-bot

## Quick Start


```
create .env file, enter encryption key after running the following command: (openssl rand -hex 32) 
N8N_ENCRYPTION_KEY=

docker compose up -d
```
